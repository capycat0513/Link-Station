# Link Station

I created 'Link Station,' a web service that removes the limit on the number of shortcuts displayed on Chrome's 'new tab' page. To keep hosting costs at zero while ensuring faster performance than any alternative, I utilized Cloudflare Workers and LocalStorage. Further details are provided below.

### 📌 Overview

### ✨ Key Features
* **Unlimited shortcuts:** Easily add and delete links without limitations.
* **Smart sorting:** Organize by Newest, Recently Used, or Most Visited.
* **Real-time search:** Find your shortcuts instantly with a live search bar.
* **$0 Server costs:** Built with a serverless architecture for zero hosting fees.

### 🛠 Tech Stack
* Cloudflare Workers, JavaScript, HTML5, CSS3
